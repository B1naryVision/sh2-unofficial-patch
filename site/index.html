Two minutes, three steps

Installing it

If you can find a folder and drag a file into it, you can do this. There is no installer to run and nothing to configure.

  1. 1

    Download the patch

    Grab the newest release and unzip it. Inside you will find d3d9.dll — that is the patch — along with an optional settings file you can ignore for now.

    Download v0.7.0

    Windows says the file is unsafe

    That warning appears for any small program not signed by a company that paid for a certificate — which no free community project does. It is not a sign that anything is wrong with the file.

    Every release is built automatically from the public source code, and each download is published with a checksum and a build record proving which code produced it. Both are on the release page if you would like to check.

  2. 2

    Put it in your Stronghold 2 folder

    Drop d3d9.dll into the folder the game itself lives in — the one containing Stronghold2.exe. Not a subfolder, not your documents. Right beside the game.

    On most machines that is:

    C:\Program Files (x86)\Steam\steamapps\common\Stronghold 2
    Show me how to find it from Steam
    1. Open Steam and go to your Library.
    2. Right-click Stronghold 2 in the list.
    3. Choose Manage → Browse local files.
    4. Windows opens the exact folder you need. Drop the file in there.
  3. 3

    Start the game as you always do

    That is the whole installation. Launch Stronghold 2 through Steam and the patch loads by itself — no menu to open, nothing to switch on.

    You should go straight to the main menu without the Firefly logo video. That is how you know it is working.

    How do I remove it later?

    Delete d3d9.dll from that same folder. The game returns to exactly how it was, and every save still works.

Optional

The download also contains sh2-unofficial-patch.ini. Copy it next to d3d9.dll only if you want to change the shortcut keys or switch on the optional camera features. You never have to open it — the keys can also be changed from inside the game with Ctrl+Shift+O.

To change the patch's keys, you do not need this file at all. Press Ctrl+Shift+O while playing, click the shortcut you want to change, and press the key you would rather use. It saves itself.
